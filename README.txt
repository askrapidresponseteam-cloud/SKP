SKP WEBSITE - COMPLETE HTML EXPORT

34 pages, all images, fonts, CSS and JavaScript are included.

QUICK PREVIEW
Extract the ZIP and open index.html. Static pages, images, fonts, menus and links work locally. Files can also be hosted in a subfolder.

VIDEO PLAYBACK
The Founder’s Corner includes the supplied film in an embedded player with in-page controls. The video streams from YouTube; it is not a downloaded video file. Use a local web server or website hosting for video playback, because YouTube requires a valid web origin.

On macOS: right-click Start-Preview.command, choose Open (Python 3 required).
Or open Terminal in this folder and run:
python3 -m http.server 8000
Then open http://localhost:8000

HOSTING
Upload this folder’s contents to static web hosting. No build or installation is required.

The enquiry form prepares text for SKP’s official contact page; it does not send messages directly. Concept campaign photography is distinguished from the real official photograph of Sampath Shetty in Founder’s Corner.

WHAT IS NEW IN THIS BUILD
Shop (retail and wholesale), product pages with spec sheets, cart and checkout, instant export quote and sample booking, lot traceability with QR, certificates, buyer portal, site search (press / or Ctrl+K), five languages, offline support.

DEMO MODE
Prices, certificates, lot records, freight rates, payment and sign in are SIMULATED and labelled as demo data on screen.
Edit data/catalog.js to add SKP's real rate card, certificates and lots, then set demo to false.
Real card payments and real buyer accounts need a payment gateway and a backend.

LANGUAGES
English, Kannada, Hindi, Arabic and German. Edit i18n.js to change or add wording.
